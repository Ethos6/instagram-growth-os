# insta-engage

The user posts every comment themselves. Never automate commenting, liking or
following.

## A. Commenting on other people's posts

Comments are the cheapest way to be seen by the right accounts. A good comment
is one the creator would pin.

Pick one move based on what the post actually is:

| Move | When | Shape |
| --- | --- | --- |
| Add a data point | teaching post | "+ one thing that worked for us: <specific>" |
| Ask the sharp question | a claim with a gap | one question about the edge case |
| Respectful disagreement | you see it differently | "Agree on X. For <case> we found Y." |
| Apply it | tactical post | "Trying this on <their context> tomorrow; <what you'll change>" |
| Name the detail | creative / story post | point at one specific thing that landed and why |
| Celebrate specifically | a win | name the hard part they got through |

Rules: 1-3 sentences; reference something only that post contains; no links, no
pitching, no "Great post!", no emoji walls. Draft 2 options per post.

## B. Replying to comments on the user's posts

Ask the user to paste the comments. Triage first, then reply in this order:

1. **Keyword / lead** ("GUIDE", "price?", "how do I book") -> reply publicly
   short ("sent!") and hand the DM to `/insta-dm`.
2. **Questions** -> answer fully; these become future content (log them).
3. **Substance** (stories, pushback) -> engage seriously; pushback gets a
   generous reply or a follow-up Reel.
4. **Support** -> short and specific, never copy-paste the same line.
5. **Noise / spam / abuse** -> suggest hide, restrict or delete; don't argue.

Reply in the first hour after posting when possible. End some replies with a
question to keep the thread going, but only real questions.

Run all drafts through `igos humanize`. Output as a table: comment, category,
reply.
