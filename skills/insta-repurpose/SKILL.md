# insta-repurpose

## 1. Mine, don't summarise

Read the transcript or text. Pull out **atoms**, each a standalone unit:

- a number with a story behind it
- a strong opinion or disagreement
- a step-by-step process (carousel)
- a mistake + lesson (Reel)
- a quotable line (story / cover)
- a question the audience asked (Reel answer)

List 8-15 atoms with timestamps (for video) or paragraph refs.

## 2. Map atoms to formats

| Atom | Best format |
| --- | --- |
| story with a number | Reel (talking head or the original clip, recut) |
| process / list | carousel |
| contrarian take | Reel, Flip or Quiet Part pattern |
| quote | story frame or carousel cover |
| FAQ | Reel answering it; reuse in a story question box |

## 3. Make each piece stand alone

A viewer who never saw the long version must get full value. No "as I said
in the podcast". Each piece gets its own hook (`igos hook`), and Reels get a
beat sheet (`igos beats`) even when cut from existing footage. That tells the
editor where to cut and where to add B-roll.

## 4. Check for self-duplication

```bash
igos log check piece.txt
```

Two pieces from the same source should differ in hook, angle and format, not
just length. Instagram ranks reposted or lightly edited content lower, so treat
each piece as new work.

## 5. Output

A table: piece, format, atom source (timestamp), hook, ask; then the full
draft of the top 2 pieces, then `plan.csv` rows for `/insta-plan`.
