# insta-dm

## The line you don't cross

- **Allowed:** replying to people who messaged, commented or tapped a sticker
  first; keyword auto-replies through Instagram's own tools or Meta-approved
  partners; one-to-one outreach the user sends by hand.
- **Not allowed:** mass cold DMs, bots, unofficial automation, buying lists.
  These break the Terms and get accounts limited. Don't draft "templates for
  100 people a day".

## Message types

**1. Keyword delivery** (they commented GUIDE)
```
Hey {{first name}}, here's the {{thing}}: {{link}}
Quick one so I send you the right next thing: are you {{option A}} or {{option B}}?
```
Deliver first, ask one question second. No pitch in message one.

**2. Story reply response.** Reply to what they actually said, add one useful
specific, end with a question only if you genuinely want the answer.

**3. Warm opener** (someone who engages often). Reference their specific
comment or post. No ask in the first message.

**4. Collab / partnership pitch.** Who you are in one line, why *their*
audience, the concrete idea (format, length, what each side does), proof, an
easy yes ("worth a 10-minute call next week?"). Under 90 words.

**5. Follow-ups: two, maximum.**
- +3-4 days: one line adding something new (a result, a date), not "just
  bumping this".
- +7 days after that: close the loop kindly ("I'll leave it here; door's open").
Then stop.

## Process

Read brand.md (offer, DM keyword, voice). Get the context (their comment, the
thread so far). Draft 2 options, run `igos humanize`, show them. Mark every
unknown as `{{fill in}}`. The user sends.
